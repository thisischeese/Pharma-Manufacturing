# SOP-QC-020 원료 입고 시험 — 주성분(API)

> [합성 문서] 저장소의 배치별 RCA 결과(notebooks/rca_batches)를 바탕으로 만든 가상 SOP. 적용 범위는 제품 17·23에 쓰는 API.

## 1. 목적
입고된 API 로트의 시험 항목과 적합 판정을 정한다.

## 2. 시험 항목
함량, 순도(총 유연물질), 입도(D10·D50·D90), 수분을 시험한다.

## 3. 판정
각 항목이 허가 사항의 규격 범위 안이면 적합으로 판정하고 사용을 승인한다. 입도 규격은 용출 시험 결과를 근거로 정해져 있다.

## 4. 기록
시험 결과는 LIMS에 등록하고 로트 번호로 배치 기록서와 연결한다.
