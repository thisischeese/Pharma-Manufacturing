# SOP-QC-031 공정 중 시험(IPC) — 정제 무게

> [합성 문서] 저장소의 배치별 RCA 결과(notebooks/rca_batches)를 바탕으로 만든 가상 SOP. 적용 범위는 제품 17·23의 타정 공정.

## 1. 목적
타정 중 정제 무게를 확인하는 공정 중 시험의 주기와 판정을 정한다.

## 2. 측정 주기
본생산 중 30분마다 정제 20정의 무게를 재고 평균과 상대표준편차(RSD)를 기록한다. 셋업 중에는 작업자가 시험 타정 정제를 필요할 때 측정한다.

## 3. 자동 무게 판정(SREL)
타정기는 압축력 신호로 정제 무게를 추정해 판정 한계를 벗어난 정제를 자동 배출한다. 판정 한계는 설비 공급사 기본값을 사용하며 셋업과 본생산에 같은 값을 쓴다.

## 4. 센서 확인
압축력 센서는 연 1회 교정한다.
